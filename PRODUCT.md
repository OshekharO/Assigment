# TaskFlow — PRODUCT.md

Product: TaskFlow
Category: Project management SaaS
Audience: Small-to-mid software and product teams (5–50 people) who need to track work without enterprise overhead.
Primary action on this surface: Request a demo (conversion = form submission).
Offer: A single place to plan work, assign tasks, set deadlines, and track progress on a visual board.
Product truth: TaskFlow is a task board with columns, assignees, due dates, and priorities. It does not include time tracking, invoicing, or resource planning.
Constraints: Static HTML/CSS/JS only. No backend. No real customer data. All product UI shown is illustrative and labeled synthetic where a visitor could mistake it for live.
Brand voice: Professional, calm, direct. Sentence case. No hype words (revolutionize, supercharge, cutting edge, effortless).
Design mode: Persuade.
Layout type: A — Classic hero plus sections (product is understandable from a hero visual).
